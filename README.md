## Features

- Talismans and matching rings for fire resistance, water breathing, night vision, haste, speed and jump boost, invisibility, wither immunity and item magnetism.
- Talismans can be found in dungeon, mineshaft, desert temple and stronghold loot chests.
- Effects stay active only while the talisman is worn, including across logouts and deaths.
- Optional Thaumcraft research, Blood Magic soul-bound talismans and Botania integration.
- In-game config screen.

## Dependencies

- [![git](images/icons/git.png) Baubles-Expanded](https://github.com/GTNewHorizons/Baubles-Expanded) (required)
- Thaumcraft, [![git](images/icons/git.png) Blood Magic](https://github.com/GTNewHorizons/BloodMagic), [Botania](https://github.com/GTNewHorizons/Botania) (optional)
